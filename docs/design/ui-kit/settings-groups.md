# Settings groups

[UI kit](../UI-KIT.md) · Tabs and order: [Settings](settings.md).

| Group | Contents |
|---|---|
| Monitoring | SettingsCard "Background process history" (icon `history`) + Toggle On/Off; caption "Collect process usage while the window is closed. 5 min at 0.5 s."; a switch confirms the new state there, a write error reverts it |
| Tile appearance | Expanders with a summary on the right ("120 · 6 · 4 px"). "Sizes and spacing" (open): tile width 80–180 (CPU and GPU; RAM 20 px narrower, NET and DISK 8 px wider), tile spacing 0–20, corner radius 0–18 (px). "Typography": header 7–15, main value 9–20, temperature, upload and write 7–16, value X/Y offsets −5–5 (px). "Tile charts": line width 0.5–3 px, area opacity %, chart left inset, fade start and length (px), chart visibility on the left %, CheckBox "Dashed temperature line". "Colors" ([Colors](settings-alerts-and-colors.md#colors)), summary "14 elements · 2 themes" or "changed: N". Slider row: label, 220 Slider, 64 field, unit |
| Alerts | Expander "Temperature and memory" (open): range rows CPU temperature °C (default 65–80), GPU temperature °C (70–80), RAM usage % (85–95), scale 30–120 °C or 0–100 %, each with its own Toggle; then the Sliders "Pulse intensity, %" (0–80, default 20) and "Pulse period, s" (0.5–6, default 2). Expander "Number color" (open): CPU load, GPU load, RAM usage % (default 80–85, scale 50–101); the tile number reddens between the thresholds. Summaries "3 rules" |
| Language | SettingsCard "Display language" (icon `globe`, caption "Applies immediately, no restart needed") + a 160 dropdown with English and Russian, each language named in itself. Applies immediately. Until one is chosen: Russian if it is the display language or a keyboard layout, otherwise English. Stored in `taskbar-metrics.language` |
| Window appearance | A card with two rows. "Window theme": icon `palette`, caption ""System" follows the Windows app theme", on the right a 160 dropdown: "System" / "Light" / "Dark"; a choice applies at once and closes the list, stored in `taskbar-metrics.theme`. "Chart line width" (after a separator): icon `chart`, caption "Total load; pinned processes in proportion" 12 `text2`, on the right a 200 px Slider (1–4, step 0.25) and the value "1 px" 12 `text2`. The total load line takes this value, pinned processes ×1.25/1.5, the hovered process ×1.75/1.5. Stored in `taskbar-metrics.chart`; default 1 px. |
| Startup and window | A card with two CheckBoxes, icons `power` and `layout` on the left, a caption 12 `text2` under the checkbox text (indent 26). "Start when signing in to Windows" — the `Taskbar Metrics` value in `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`; caption "Taskbar tiles and the CPU temperature sensor"; the value starts `TaskbarMetrics.exe --autostart`; the window does not open at sign-in. "Reset the window size and position when it closes" — on by default; the caption describes where the window will open. A write error reverts the checkbox and puts the reason in the caption |
